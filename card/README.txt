بطاقة التواصل — تعليمات سريعة
==============================

الرابط النهائي للبطاقة:
https://mohamedsalahabdelhamid.github.io/mohamed-salah/card/

أول مرة — رفع البطاقة على GitHub
---------------------------------
1. افتح الريبو: https://github.com/mohamedsalahabdelhamid/mohamed-salah
2. اعمل مجلد اسمه card جوّه الريبو.
3. ارفع كل الملفات اللي في المجلد ده داخل card/
   (index.html, styles.css, app.js, data-default.js, links.json,
    edit.html, edit.js, assets/profile.png, qr.svg, qr.png)
4. اعمل Commit + Publish.
5. جرّب الرابط: https://mohamedsalahabdelhamid.github.io/mohamed-salah/card/
6. اطبع qr.png أو استخدم qr.svg.

تعديل الروابط أو النصوص براحتك
--------------------------------
1. افتح: https://mohamedsalahabdelhamid.github.io/mohamed-salah/card/edit.html
2. غيّر الاسم / الترحيب / النبذة / الروابط. تقدر:
   - تضيف رابط بالزر «+ إضافة رابط»
   - تشيل رابط بزر «حذف»
   - تعيد الترتيب بـ ↑ و ↓
   - تخفي رابط مؤقتاً بإلغاء علامة «ظاهر في البطاقة»
3. اضغط «نسخ JSON» (أو «تنزيل links.json»).
4. روح على links.json في الريبو → Edit (القلم) → الصق المحتوى الجديد
   → Commit changes.
5. خلاص: أي حد يفتح الكيو ار هيشوف التعديل فوراً. الكيو ار ما اتغيرش.

ملاحظات مهمة
-------------
- التعديل محفوظ كمان في المتصفح تلقائياً (مسودة)، لو حصلت مشكلة ترجع تلاقيه.
- زر «استعادة الافتراضي» بيرجّعك للنسخة المنشورة على GitHub.
- الكيو ار مولّد من الرابط الثابت فوق. لو غيّرت مسار المجلد أو اسم الريبو،
  لازم تتعمل كيو ار جديد.
- الصورة الموجودة assets/profile.png هي نفس الصورة اللي بعتها (500x500).
  عشان تبدّلها، استبدل الملف بالاسم نفسه.
